# dx-headers

## Notes
Symbols are determined from the symbol map from the Switch 2 update of the game, but sizes and Address comments are written for the 32-bit Switch 1 executable (note that, for the international release, versions 1.0.0 through 1.0.2 are identical).

If a function isn't present/does not have its own dedicated address (i.e. due to deadstripping, inlining, etc.), it will be marked as "deleted."
